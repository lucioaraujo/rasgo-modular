Installation

How to install Rasgo Modular on Windows, macOS and Linux, what it needs from the computer and where it keeps things.

Three ways to use it

ApplicationThe complete instrument, on its own on the computer: seeds, VARIA, cables that play, recording. Windows, macOS and Linux. Installation right below.
DAW pluginThe same instrument on a DAW instrument track: VST3 (Reaper, Bitwig, Ableton Live, Ardour, Cubase, Studio One, FL Studio and others) and LV2 on Linux. Its own download, next to the application.
VCV Rack plugin100 of the modules inside VCV Rack 2, to combine with modules by other authors. Download from the rasgo-modular-vcv repository.

All three are free and open source, and can live side by side on the same computer.

Before you start

The packages are under Download, on the home page, and on the GitHub releases page. The Windows and macOS security warnings are expected and appear only the first time.

Application: Windows

  1. Download rasgo-modular-<version>-windows-x64.exe and open it.
  2. Windows shows "Windows protected your PC": click "More info", then "Run anyway".
  3. If Windows asks for administrator permission, click "Yes".
  4. Click "Next" to the end. Rasgo Modular is then in the Start menu and on the desktop; each new version replaces the previous one.

Without installing: unzip the .zip and open Rasgo Modular.exe. If it does not open, press Win + R, type %APPDATA%\rasgo-modular and send arranque.log in a GitHub issue: its last line says where startup stopped.

Application: macOS

  1. Download rasgo-modular-<version>-macos-universal.dmg. It works on Intel and Apple Silicon Macs.
  2. Open the .dmg and drag Rasgo Modular into Applications.
  3. Open the app. The first time, macOS blocks it, because it is signed ad hoc, without a paid Apple Developer ID. Click "OK".
  4. Allow the app once: in System Settings → Privacy & Security, click "Open Anyway" and confirm. On macOS 14 or earlier: right-click the app in Finder → Open → Open.
  5. When you turn on the ON button of the SIGNAL-IN module, macOS asks for the microphone: allow it if you want to play with audio input.

If the button does not appear, use Terminal. The command removes the quarantine mark macOS puts on every downloaded file:

xattr -dr com.apple.quarantine "/Applications/Rasgo Modular.app"

Application: Linux

  • Ubuntu, Debian and Mint: double-click the .deb, or sudo apt install ./rasgo-modular-<version>-linux-x86_64.deb.
  • Other distributions, AppImage: make it executable (Properties → allow executing, or chmod +x) and open it.
  • Other distributions, .tar.gz: unpack it and run ./install.sh, which installs for your user, without root.

DAW plugin (VST3 and LV2)

Download the file for your system under Download, on the home page (the Plugin buttons), or from the GitHub releases page. Close the DAW before copying.

  • Windows: unzip rasgo-modular-plugin-<version>-windows-x64.zip and copy the Rasgo Modular.vst3 folder to C:\Program Files\Common Files\VST3\ (Windows asks for administrator permission).
  • macOS: unzip rasgo-modular-plugin-<version>-macos-universal.zip (Intel and Apple Silicon) and copy Rasgo Modular.vst3 to ~/Library/Audio/Plug-Ins/VST3/ (in Finder: Go → Go to Folder). If the DAW rejects the plugin, allow it once in Terminal:
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Rasgo Modular.vst3"
  • Linux: unpack rasgo-modular-plugin-<version>-linux-x86_64.tar.gz; copy Rasgo Modular.vst3 to ~/.vst3/ and Rasgo Modular.lv2 to ~/.lv2/.

Open the DAW and ask it to rescan plugins. Create an instrument track and choose Rasgo Modular (maker RASGO); its window opens from the plugin's edit button. The patch is saved in the project; the DAW's transport reaches SIGNAL-IN as MIDI clock, and VARIA and Master accept automation.

Tested by the author on Linux, in Ardour 8.4. On Windows and macOS, continuous integration loads the plugin and checks that it sounds and that its state comes back the same. Logic and GarageBand use the Audio Unit format, planned for a coming version. In Infinite 2.0.0, opening the plugin window closes the program (a defect logged on its side).

VCV Rack plugin

  1. Download the .vcvplugin for your system from the releases page of the rasgo-modular-vcv repository (github.com/lucioaraujo/rasgo-modular-vcv/releases): win-x64 for Windows, mac-arm64 for Apple Silicon Macs, mac-x64 for Intel Macs, lin-x64 for Linux.
  2. In VCV Rack 2, choose Help → Open user folder.
  3. Put the file in the plugins-<system>-<arch> folder there (for example plugins-win-x64).
  4. Restart VCV Rack. The modules appear in the module browser under the brand Rasgo.

Every control has its tooltip; right-click a module for its manual and credits. Polyphony up to 16 voices. SIGNAL-IN, POLY-IN, NOTE-OUT, MIXER and MASTER stay in the application, since VCV Rack has its own.

With other programs

Rasgo Modular is a standalone application that talks to DAWs, other synthesizers and machines through the system's audio and MIDI. The way in is the SIGNAL-IN module: switch it ON and patch one of its outputs. From then on it receives sound, notes and tempo; NOTE-OUT sends notes out.

  • Inside a DAW, as a plugin (VST3 and LV2): see the “DAW plugin” section, above.
  • Sound from another program into Rasgo: on Linux, connect the program's output to Rasgo Modular's input in PipeWire or JACK (qpwgraph, Helvum or Carla); on macOS, use a virtual device such as BlackHole; on Windows, VB-Cable. The sound arrives at SIGNAL-IN's L and R outputs.
  • Rasgo's sound in a DAW: the same path the other way round. Rasgo Modular's output becomes the input of a DAW track (Ardour, Reaper, Bitwig, Live, Infinite and others) to record or process.
  • Notes: a MIDI keyboard or a DAW MIDI track arrives at SIGNAL-IN (1V/O, GATE, VEL and CC). NOTE-OUT sends the patch's notes to another instrument.
  • The DAW's tempo (MIDI clock): in the DAW, turn on MIDI clock output to the port Rasgo Modular listens to. Patch SIGNAL-IN's CLK into the CLOCK's EXT and RST into the CLOCK's RST: the patch follows the DAW's tempo and "one" and stops on STOP. DIV picks the division; the eighth note, the default, matches the CLOCK's MULT 2. RUN stays high while the DAW plays.
  • In VCV Rack: see the “VCV Rack plugin” section, above.
  • MIDI ports between programs: on Linux, the ports appear in the system itself (ALSA); on macOS, use the IAC driver; on Windows, a virtual MIDI cable such as loopMIDI. Rasgo Modular listens to the MIDI inputs that exist when SIGNAL-IN is switched on: open the DAW first.

Where things live

  • State and preferences: ~/.config/rasgo-modular/ on Linux (session, patches, language); on macOS and Windows, the system's application data folder.
  • Recordings: ~/Music/RasgoModular/, the .wav and the take's score, with the streaming delivery version beside them.

If there is no sound

Rasgo Modular sounds when it opens. With no sound, check the system audio output, the STANDBY button (which mutes the master) and the gain of the MASTER module. For anything else, write to rasgo.instruments@gmail.com with your system, the version and what you saw.
