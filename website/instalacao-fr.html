Installation

Comment installer Rasgo Modular sous Windows, macOS et Linux, ce qu'il demande à l'ordinateur et où il range les choses.

Trois façons de l’utiliser

ApplicationL’instrument complet, seul sur l’ordinateur : seeds, VARIA, câbles qui jouent, enregistrement. Windows, macOS et Linux. Installation juste en dessous.
Plugin pour DAWLe même instrument sur une piste d’instrument de la DAW : VST3 (Reaper, Bitwig, Ableton Live, Ardour, Cubase, Studio One, FL Studio et d’autres) et LV2 sous Linux. Téléchargement à part, à côté de l’application.
Plugin pour VCV Rack100 des modules dans VCV Rack 2, à combiner avec les modules d’autres auteurs. Téléchargement sur le dépôt rasgo-modular-vcv.

Les trois sont gratuites et open source, et peuvent cohabiter sur le même ordinateur.

Avant de commencer

Les paquets sont dans Télécharger, sur la page d'accueil, et sur la page des releases GitHub. Les avertissements de sécurité de Windows et de macOS sont attendus et n'apparaissent que la première fois.

Application : Windows

  1. Téléchargez rasgo-modular-<version>-windows-x64.exe et ouvrez-le.
  2. Windows affiche « Windows a protégé votre ordinateur » : cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
  3. Si Windows demande l'autorisation d'administrateur, cliquez sur « Oui ».
  4. Cliquez sur « Suivant » jusqu'à la fin. Rasgo Modular est alors dans le menu Démarrer et sur le bureau ; chaque nouvelle version remplace la précédente.

Sans installer : décompressez le .zip et ouvrez Rasgo Modular.exe. S'il ne s'ouvre pas, appuyez sur Win + R, tapez %APPDATA%\rasgo-modular et envoyez arranque.log dans une issue GitHub : sa dernière ligne dit où le démarrage s'est arrêté.

Application : macOS

  1. Téléchargez rasgo-modular-<version>-macos-universal.dmg. Il fonctionne sur les Mac Intel et Apple Silicon.
  2. Ouvrez le .dmg et glissez Rasgo Modular dans Applications.
  3. Ouvrez l'app. La première fois, macOS la bloque, car elle a une signature ad hoc, sans Developer ID Apple payant. Cliquez sur « OK ».
  4. Autorisez l'app une fois : dans Réglages Système → Confidentialité et sécurité, cliquez sur « Ouvrir quand même » et confirmez. Sous macOS 14 ou antérieur : clic droit sur l'app dans le Finder → Ouvrir → Ouvrir.
  5. Quand vous allumez le bouton ON du module SIGNAL-IN, macOS demande le microphone : autorisez-le pour jouer avec une entrée audio.

Si le bouton n'apparaît pas, utilisez le Terminal. La commande retire la marque de quarantaine que macOS pose sur chaque fichier téléchargé :

xattr -dr com.apple.quarantine "/Applications/Rasgo Modular.app"

Application : Linux

  • Ubuntu, Debian et Mint : double-cliquez sur le .deb, ou sudo apt install ./rasgo-modular-<version>-linux-x86_64.deb.
  • Autres distributions, AppImage : rendez-le exécutable (Propriétés → autoriser l'exécution, ou chmod +x) et ouvrez-le.
  • Autres distributions, .tar.gz : décompressez et lancez ./install.sh, qui installe pour votre utilisateur, sans root.

Plugin pour DAW (VST3 et LV2)

Téléchargez le fichier de votre système dans Télécharger, sur la page d’accueil (boutons Plugin), ou sur la page des releases GitHub. Fermez la DAW avant de copier.

  • Windows : décompressez rasgo-modular-plugin-<version>-windows-x64.zip et copiez le dossier Rasgo Modular.vst3 dans C:\Program Files\Common Files\VST3\ (Windows demande l’autorisation d’administrateur).
  • macOS : décompressez rasgo-modular-plugin-<version>-macos-universal.zip (Intel et Apple Silicon) et copiez Rasgo Modular.vst3 dans ~/Library/Audio/Plug-Ins/VST3/ (dans le Finder : Aller → Aller au dossier). Si la DAW refuse le plugin, autorisez-le une fois dans le Terminal :
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Rasgo Modular.vst3"
  • Linux : décompressez rasgo-modular-plugin-<version>-linux-x86_64.tar.gz ; copiez Rasgo Modular.vst3 dans ~/.vst3/ et Rasgo Modular.lv2 dans ~/.lv2/.

Ouvrez la DAW et demandez-lui de rechercher les plugins. Créez une piste d’instrument et choisissez Rasgo Modular (fabricant RASGO) ; la fenêtre s’ouvre par le bouton d’édition du plugin. Le patch est gardé dans le projet ; le transport de la DAW arrive au SIGNAL-IN comme horloge MIDI, et VARIA et Master acceptent l’automation.

Testé par l’auteur sous Linux, dans Ardour 8.4. Sous Windows et macOS, l’intégration continue charge le plugin et vérifie qu’il sonne et que son état revient identique. Logic et GarageBand utilisent le format Audio Unit, prévu pour une prochaine version. Dans Infinite 2.0.0, ouvrir la fenêtre du plugin ferme le programme (défaut enregistré de son côté).

Plugin pour VCV Rack

  1. Téléchargez le .vcvplugin de votre système sur la page des releases du dépôt rasgo-modular-vcv (github.com/lucioaraujo/rasgo-modular-vcv/releases) : win-x64 pour Windows, mac-arm64 pour Mac Apple Silicon, mac-x64 pour Mac Intel, lin-x64 pour Linux.
  2. Dans VCV Rack 2, choisissez Help → Open user folder.
  3. Placez le fichier dans le dossier plugins-<système>-<architecture> qui s’y trouve (par exemple plugins-win-x64).
  4. Rouvrez VCV Rack. Les modules apparaissent dans le navigateur de modules sous la marque Rasgo.

Chaque contrôle a son infobulle ; clic droit sur un module pour le manuel et les crédits. Polyphonie jusqu’à 16 voix. SIGNAL-IN, POLY-IN, NOTE-OUT, MIXER et MASTER restent dans l’application, car VCV Rack a les siens.

Configuration requise

WindowsWindows 10 (1607 ou ultérieur) ou 11, 64 bits
macOS10.15 ou ultérieur, Intel et Apple Silicon
Linuxx86-64 avec glibc 2.35 ou plus récente ; testé au lancement sous Debian 12, Ubuntu 24.04, Fedora et Arch
Processeur64 bits, deux cœurs ou plus ; mesuré sur un Intel Core i5-6500 : l'app utilise d'un tiers à la moitié d'un cœur
Mémoire et disqueenviron 55 Mo en usage et 20 Mo sur le disque
Écran1280 × 760 ou plus grand
Audiotoute sortie du système ; microphone et clavier MIDI sont facultatifs (module SIGNAL-IN)

Avec d’autres logiciels

Rasgo Modular est une application autonome qui dialogue avec les DAW, d’autres synthétiseurs et des machines par l’audio et le MIDI du système. La porte d’entrée est le module SIGNAL-IN : allumez ON et câblez une de ses sorties. Il reçoit alors le son, les notes et le tempo ; NOTE-OUT envoie les notes vers l’extérieur.

  • Dans une DAW, comme plugin (VST3 et LV2) : voir la section « Plugin pour DAW », plus haut.
  • Dans VCV Rack : voir la section « Plugin pour VCV Rack », plus haut.
  • Le son d’un autre logiciel dans Rasgo : sous Linux, reliez la sortie du logiciel à l’entrée de Rasgo Modular dans PipeWire ou JACK (qpwgraph, Helvum ou Carla) ; sous macOS, utilisez un périphérique virtuel comme BlackHole ; sous Windows, VB-Cable. Le son arrive sur les sorties L et R de SIGNAL-IN.
  • Le son de Rasgo dans une DAW : le même chemin en sens inverse. La sortie de Rasgo Modular devient l’entrée d’une piste de la DAW (Ardour, Reaper, Bitwig, Live, Infinite et d’autres) pour enregistrer ou traiter.
  • Les notes : un clavier MIDI ou une piste MIDI de la DAW arrive sur SIGNAL-IN (1V/O, GATE, VEL et CC). NOTE-OUT envoie les notes du patch vers un autre instrument.
  • Le tempo de la DAW (horloge MIDI) : dans la DAW, activez l’envoi de l’horloge MIDI vers le port qu’écoute Rasgo Modular. Câblez le CLK de SIGNAL-IN sur l’EXT du CLOCK et le RST sur le RST du CLOCK : le patch suit le tempo et le « un » de la DAW et s’arrête au STOP. DIV choisit la division ; la croche, par défaut, s’accorde au MULT 2 du CLOCK. RUN reste haut tant que la DAW joue.
  • Ports MIDI entre logiciels : sous Linux, les ports apparaissent dans le système (ALSA) ; sous macOS, utilisez le pilote IAC ; sous Windows, un câble MIDI virtuel comme loopMIDI. Rasgo Modular écoute les entrées MIDI présentes quand SIGNAL-IN est allumé : ouvrez d’abord la DAW.

Où vivent les choses

  • État et préférences : ~/.config/rasgo-modular/ sous Linux (session, patches, langue) ; sous macOS et Windows, le dossier de données d'application du système.
  • Enregistrements : ~/Music/RasgoModular/, le .wav et la partition de la prise, avec la version de livraison pour le streaming à côté.

S'il n'y a pas de son

Rasgo Modular sonne dès l'ouverture. Sans son, vérifiez la sortie audio du système, le bouton ATTENTE (qui coupe le master) et le gain du module MASTER. Pour autre chose, écrivez à rasgo.instruments@gmail.com avec votre système, la version et ce qui s'est affiché.
